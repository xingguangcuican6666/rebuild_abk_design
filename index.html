19如何使用

引入顺序有讲究：字体 → tokens → base → 组件 → 页面自己的样式。 交互能力全部通过 data-abk-* 属性声明，静态页面不需要写脚本。

最小引入

<link rel="stylesheet" href="assets/css/fonts.css"> <link rel="stylesheet" href="assets/css/tokens.css"> <link rel="stylesheet" href="assets/css/base.css"> <link rel="stylesheet" href="assets/css/components.css"> <link rel="stylesheet" href="assets/css/forms.css"> <link rel="stylesheet" href="assets/css/overlays.css"> <link rel="stylesheet" href="assets/css/navigation.css"> <script src="assets/js/abk-ui.js" defer></script>

声明式交互

<button data-abk-dialog-open="dlg">打开</button> <button data-abk-sheet-open="sheet">弹层</button> <button data-abk-menu="menu">菜单</button> <button data-abk-toast="已保存">提示</button> <script> ABK.toast.show("构建完成", { type: "success" }); </script>
移植到 Kotlin 时，--accent → MaterialTheme.colorScheme.primary， --r-lg → Shapes.medium，手写体 → 同名字体资源； 交互层逻辑（焦点陷阱、Toast、分段选择）在 Compose 里各有对应实现。
ABK UI · 先网页定稿，再写 Kotlin 版本 来自 ABK 的界面需求沉淀
